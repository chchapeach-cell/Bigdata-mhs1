🚀 ชุดไฟล์สำหรับติดตั้งบน Hostatom (Standalone Web & MySQL)

คู่มือการติดตั้งระบบ MHS1 BIGDATA บน Hostatom

ชุดไฟล์นี้เป็นชุดที่แยกออกมาโดยเฉพาะสำหรับติดตั้งบน Web Hosting ของ Hostatom โดยที่ระบบเดิมบนคลาวด์ยังคงอยู่ครบถ้วน 100%

1 อัปโหลดไฟล์ทั้งหมดขึ้น Hostatom ผ่าน File Manager

1. เข้าสู่ cPanel ของ Hostatom แล้วคลิกที่เมนู File Manager

2. ดับเบิ้ลคลิกเข้าโฟลเดอร์ public_html (หรือโฟลเดอร์ของ Subdomain)

3. คลิกปุ่ม Upload ด้านบน แล้วเลือกไฟล์ ZIP ชุดนี้อัปโหลดขึ้นไป

4. เมื่ออัปโหลดเสร็จ ให้คลิกขวาที่ไฟล์ ZIP แล้วเลือก Extract (แตกไฟล์) ลงใน public_html

2 สร้างฐานข้อมูล MySQL และ User ใน cPanel

1. ใน cPanel คลิกเมนู MySQL Databases (หรือ MySQL Database Wizard)

2. สร้างชื่อฐานข้อมูลใหม่ เช่น mhs1db

3. สร้างผู้ใช้ (Create New User) และตั้งรหัสผ่านที่ปลอดภัย

4. สำคัญมาก: เลื่อนลงมาที่หัวข้อ Add User To Database เลือก User และ Database ที่เพิ่งสร้าง แล้วกด Add จากนั้นติ๊กเลือก ALL PRIVILEGES แล้วกด Make Changes

3 นำเข้าโครงสร้างตารางผ่าน phpMyAdmin

1. กลับมาที่หน้าหลักของ cPanel คลิกเปิด phpMyAdmin

2. คลิกเลือกชื่อฐานข้อมูลของคุณที่แถบเมนูด้านซ้าย

3. คลิกแท็บ Import (นำเข้า) ด้านบน

4. กด Choose File แล้วเลือกไฟล์ database/01_mhs1_schema_mysql.sql จากในเครื่องของคุณ แล้วกด Import (หรือ Go) ด้านล่าง

4 ตั้งค่ารหัสผ่านฐานข้อมูลใน api/config.php

1. ใน File Manager บน cPanel เข้าไปที่โฟลเดอร์ public_html/api/

2. คลิกขวาที่ไฟล์ config.php แล้วเลือก Edit

3. กรอกชื่อฐานข้อมูล, ชื่อผู้ใช้, และรหัสผ่าน MySQL ที่สร้างไว้ในข้อ 2:

define('DB_HOST', 'localhost');
define('DB_NAME', 'ชื่อ_cpanel_mhs1db');  // เปลี่ยนเป็นของคุณ
define('DB_USER', 'ชื่อ_cpanel_dbuser');  // เปลี่ยนเป็นของคุณ
define('DB_PASS', 'รหัสผ่านของคุณ');      // เปลี่ยนเป็นของคุณ
define('API_SECRET', 'mhs1_bigdata_secret_2026');

4. กด Save Changes
